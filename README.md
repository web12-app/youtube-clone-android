# YouTube Clone - Android App

Simple YouTube-like Android app built with Kotlin.

## Features
- Dark theme YouTube style UI
- Video list with thumbnails
- ExoPlayer video playback
- Bottom navigation
- Fake sample data (public sample videos)

## How to build
1. Open this folder in **Android Studio** (Hedgehog or newer recommended)
2. Wait for Gradle sync
3. Connect a device / start emulator
4. Click **Run**

## Notes
- Uses sample MP4 videos from Google’s public test bucket
- Thumbnails from picsum.photos
- No real YouTube API (needs API key for production)

## Package
`com.example.youtubeclone`
